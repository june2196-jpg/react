# PR 생성

PR 준비와 생성은 서브 에이전트에게 위임하고, 상위 에이전트는 범위를 조율해 결과를 보고한다.

1. 기여 가이드, 이슈·PR 언어, 사용자 지시를 기준으로 프로젝트 대상 독자를 판단한다.
   - 해외 오픈소스 프로젝트에는 [영문 템플릿](references/pr-template.en.md)을 사용한다.
   - 한국 프로젝트에는 [한국어 템플릿](references/pr-template.ko.md)을 사용한다.
   - 대상 독자를 판단할 수 없으면 사용할 템플릿을 사용자에게 확인한다.
2. 서브 에이전트에게 현재 브랜치, 대상 베이스 브랜치, 원격 저장소, diff, 관련 커밋 조사를 맡긴다. 서브 에이전트는 확인된 사실만으로 적용 가능한 템플릿 항목을 모두 작성한다.
3. 서브 에이전트는 브랜치 푸시 여부와 외부 변경에 대한 사용자의 명시적 승인을 확인한 뒤 PR을 생성한다. 무관한 커밋을 추가하거나 테스트 결과·링크·이슈 번호를 지어내면 안 된다.
4. 상위 에이전트에게 PR URL, 베이스 브랜치, 헤드 브랜치, 선택한 템플릿, 검증 결과를 반환한다.
